# Contributing

The highest-value contributions are:

1. Implementations of `handoff-v0` in another runtime.
2. Validation tests for the schemas.
3. Honest reports that a field invites secrets or injection.

Do not open PRs that add:

- unattended wallets
- long-term plaintext memory stores
- social feeds
- shrine or sanctuary copy
- scraping other agents without consent

Open an issue first for anything that changes the charter.
